# 📸 TodoSnap 使用说明

**v1.1.1** · 把一张截图，变成一句待办

</div>

## 💡 开发原因

> 在电脑上处理工作时，常常同时打开十几个窗口来回切换，一忙起来就容易忘记本来要做什么。被各种弹窗、消息打断之后，刚才脑袋里那件事就丢了。
>
> 于是我用 **Claude Code**（主要基于 Anthropic Opus 4.8）开发了 TodoSnap。中间也试过 DeepSeek V4 Pro效果却不尽如人意，又怒充 50 块才打磨到现在的版本，基本可以稳定运行了。
>
> 本人理科专业，应用开发一窍不通，整个项目除这段话外都是 AI 写的。如果你觉得有用，就给个 Star 吧！

---

TodoSnap 是一个**极致轻量**的 Windows 桌面小工具，核心流程只有四步：

> 截图 → 粘贴 → 自动提炼成一句待办 → 钉在屏幕侧边悬浮窗，点一下圆圈即完成（带淡出动画）。

- ✅ 常驻系统托盘，离线可用  
- ✅ 单文件绿色运行，无需安装 .NET 或任何运行时  
- ✅ 数据存于本地 JSON，隐私无忧

---

## 📦 一、安装（其实不用装）

1. 将 `TodoSnap.exe` 放到任意文件夹（如 `D:\TodoSnap\`）
2. 双击 `TodoSnap.exe` 即可运行，**无需安装任何依赖**

> **💡 提示**
>
> - 首次启动可能稍慢几秒（程序在解压自带的运行时），之后即快
> - 若 Windows 弹出 *"已保护你的电脑"* 蓝色提示，点 **更多信息 → 仍要运行** 即可（未签名程序的正常提示）
> - 运行环境要求：**Windows 10 1809+** 或 **Windows 11**

---

## 🚀 二、基本使用（4 步上手）

| 步骤 | 操作 | 详情 |
|:---:|---|------|
| **1** | 📷 **截图** | 按 `Shift + Win + S` 框选屏幕区域，图片自动进入剪贴板 |
| **2** | 🪟 **唤起** | 按全局快捷键 **`Alt + \``** 或点击系统托盘图标，在窗口内按 `Ctrl + V` 粘贴截图<br>也可以直接拖拽图片文件到窗口中 |
| **3** | 🤖 **提炼** | 稍等片刻，自动生成一句待办描述并填入编辑框，你可手动修改<br>▸ 标题栏左侧有 **AI 状态灯**：灰色 = 离线 OCR · 绿色 = AI 在线<br>▸ AI 生成的结果以 **`AI:`** 前缀标注 |
| **4** | ✅ **添加** | 按回车或点击"添加待办" → 待办出现在屏幕侧边悬浮栏 |

**完成待办**：点击待办左边的圆圈按钮 → 淡出消失（同步从记录中删除）

---

## ✨ 三、悬浮待办栏新特性

| 特性 | 说明 |
|------|------|
| 🔲 **自由缩放** | 鼠标移至悬浮窗任意边/角，拖拽即可改变长宽，尺寸自动记忆 |
| 📌 **边缘吸附** | 将悬浮窗拖至屏幕 **上/下/左/右** 边缘，自动收纳为 **贴边细条 + 数字徽标**（显示剩余待办数） |
| 🎞️ **平滑展开** | 点击贴边细条 → 流畅动画恢复为正常列表窗口 |
| 🔔 **添加反馈** | 贴边状态下从主窗口添加新待办时，栏自动展开显示新内容，5–6 秒无操作后自动收回 |

## ⚙️ 四、设置主界面

打开方式：主窗口右上角 **⚙ 齿轮按钮**，或托盘右键 → **设置**

| 分区 | 功能说明 |
|:---:|---|
| 🎨 **外观** | 浅色 / 深色主题切换；背景透明度滑块（0.6–1.0），**仅影响背景层，文字始终清晰** |
| ⌨️ **快捷键** | 默认 `Alt + \`` · 点击"录制"后按下新组合键即可生效；若被其他软件占用则红字提示，自动保留原键 |
| 🤖 **在线 AI** | 填写 API Key / Endpoint / Model 并保存，即可启用在线智能分析（保存至 `%AppData%\TodoSnap\apikey.txt`） |
| 💻 **系统** | 开机自启 · 显示/隐藏待办栏 · 重置待办栏位置和尺寸 |

## 🖱️ 五、系统托盘菜单

| 菜单项 | 功能描述 |
|------|------|
| 显示主窗口 | 打开粘贴/提炼窗口（左键单击托盘图标也可） |
| 设置 | 打开设置主界面 |
| 显示/隐藏待办栏 | 切换侧边悬浮栏的显示状态 |
| 开机自启 | 勾选后开机自动运行 TodoSnap |
| 退出 | 彻底关闭程序（关闭主窗口仅隐藏至托盘） |

## 🔤 六、中文 OCR 识别（重要）

离线识别使用 Windows 内置 OCR 引擎，需先安装中文识别语言包：

> **⚡ 操作路径**
>
> 设置 → 时间和语言 → 语言和区域 → 中文 → 语言选项 → 确认已安装 **"文本识别 (OCR)"**

未安装则中文截图无法识别出文字。

---

## 🌐 七、在线 AI 模式（可选，效果更佳）

默认离线即可使用。若希望 AI 更智能地提炼待办内容，可选择以下任一方式：

### 方式一（推荐）：设置界面配置

打开「设置 → 在线 AI」，填入以下信息后点击 **"保存 API"** 即刻生效：

| 字段 | 要求 |
|------|------|
| API Key | **必填** |
| Endpoint | 可选，留空使用默认地址 |
| Model | 可选，留空使用默认模型 |

### 方式二（兼容旧版）：配置文件

将同目录的 `apikey.txt.example` 复制一份，改名为 `apikey.txt`：

```
第 1 行：API Key（必填）
第 2 行：Endpoint 地址（可选，留空 = 默认）
第 3 行：模型名称（可选，留空 = 默认）
```

### 重要说明

> - 设置界面写入的 Key 保存于 `%AppData%\TodoSnap\apikey.txt`，**优先**于 exe 同目录配置
> - 在线分析超时 5 秒或任何出错，**自动降级为离线 OCR**，不影响正常使用
> - 删除两处 `apikey.txt` 则永久走离线模式

## 💾 八、数据存储位置

| 数据类型 | 存储路径 |
|------|------|
| 待办数据 | `%AppData%\TodoSnap\tasks.json` |
| 配置信息 | `%AppData%\TodoSnap\config.json` |
| AI 密钥 | `%AppData%\TodoSnap\apikey.txt` |

> 💡 在文件资源管理器地址栏输入 `%AppData%\TodoSnap` 即可快速打开

**卸载**：删除 `TodoSnap.exe` 即可；如需彻底清除数据，一并删除上述 TodoSnap 文件夹。

## ❓ 九、常见问题

### Q1 · 双击没反应？

> 查看屏幕右下角系统托盘是否已有图标 —— 程序默认显示主窗口，若被遮挡可按 `Alt + \`` 或点击托盘图标唤出。

### Q2 · 快捷键 `Alt + \`` 不生效？

> 可能被其他软件占用。打开 设置 → 快捷键 → 点击"录制"换一个组合（如 `Ctrl + Alt + T`）。

### Q3 · 粘贴后没识别出文字？

> 多半是未安装中文 OCR 语言包，参见上方 **第六章**。

### Q4 · 待办栏不见了？

> 可能被拖到屏幕边缘吸附为细条了。查看四个屏幕边缘是否有带数字的细条；或通过托盘右键 → 显示/隐藏待办栏 恢复；或在设置中 重置待办栏位置/尺寸。

### Q5 · 单文件 exe 能发给别人吗？

> 完全可以。单文件自带运行时，对方双击即可运行。在线 AI 模式需各自配置自己的 API Key。
